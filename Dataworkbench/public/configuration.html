Credential boundary

Add the API secret on the server

The workbench deliberately has no secret input. Do not paste a key into this page, a JSON settings file, source control, browser storage, or chat. Make the key available to the Node.js process through AZURE_OPENAI_REPORTING_KEY.

  1. Open a PowerShell terminal on the host.Set the secret only for the terminal session that will start the workbench:
    $env:AZURE_OPENAI_REPORTING_KEY = Read-Host -MaskInput 'Foundry API key'
  2. Start or restart from that same terminal.The child Node.js process inherits the secret. The value is never returned to the browser.
    npm start
  3. Refresh and confirm.The runtime status should show “Configured.” For shared or hosted environments, use the platform's secret store to inject this environment variable instead of creating a user-scoped variable.
Rotation: replace the environment value and restart the server. Saving the endpoint or deployment names never changes or exposes the secret.
